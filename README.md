## About The Project

- **Source Builder Interface**: Comprehensive editor with sidebar navigation, content panels, and live UI preview for crafting AltStore and SideStore sources.
- **App Management**: Easily add and manage multiple apps with bundle IDs, developer info, version history, and download URLs.
- **News Integration**: Include news items with dates to keep sources updated with the latest information.
- **Image Hosting**: Seamless proxy API for uploading and hosting source icons and headers via freeimage.host.
- **Validation Engine**: Robust client-side validation to ensure sources meet AltStore and SideStore export requirements.
- **Platform Exports**: Validate and export sources in formats specifically tailored for AltStore or SideStore.

## Local Development

To contribute to Satuji, you can set up the project locally for development.

### Prerequisites

- Bun (for package management and runtime)

### Installation

1. Clone the repo
   ```sh
   git clone https://github.com/waruhachi/Satuji.git
   ```
2. Navigate to the project directory
   ```sh
   cd Satuji
   ```
3. Install dependencies
   ```sh
   bun install
   ```
4. Start the development server
   ```sh
   bun run dev
   ```

Your application should now be running at `http://localhost:5173`.

### Contributing

We welcome contributions! Please make a pull request with your changes. Ensure your code follows the project's linting and formatting rules.
